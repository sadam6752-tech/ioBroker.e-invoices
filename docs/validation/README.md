# Validation evidence

Output of the validators for the invoices the adapter creates: reports of the KoSIT validator (EN 16931 / XRechnung,
CII) and of veraPDF (PDF/A-3b), the sample cases in `sample-cases/` and the script `sample-cases.mjs` that makes them
(`npm run validate` runs it). The files are tool output and stay as they are; what they show, how they were made and
what they do not show is described in [docs/en/validation.md](../en/validation.md) (German version:
[docs/de/validation.md](../de/validation.md)).

On 6 November 2026 the directory and the files were given English names (review of the ioBroker repository: `docs/validierung` became `docs/validation`, `musterfaelle` became `sample-cases`, the sample cases are named like `credit-note` instead of `gutschrift`). The file names inside the reports were changed with them; the documents themselves and the verdicts are unchanged.
