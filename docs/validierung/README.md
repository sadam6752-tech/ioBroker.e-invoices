# Validation evidence

Output of the validators for the invoices the adapter creates: reports of the KoSIT validator (EN 16931 / XRechnung,
CII) and of veraPDF (PDF/A-3b), the sample cases in `musterfaelle/` and the script `musterfaelle.mjs` that makes them
(`npm run validate` runs it). The files are tool output and stay as they are; what they show, how they were made and
what they do not show is described in [docs/en/validation.md](../en/validation.md) (German version:
[docs/de/validierung.md](../de/validierung.md)).
